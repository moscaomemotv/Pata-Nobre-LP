# Pata Nobre - Landing Page Oficial

Landing Page de alta conversão para a **Luva Removedora 5 em 1 Pata Nobre**, totalmente responsiva, otimizada para carregamento ultrarrápido e independente de dependências pesadas.

---

## 📁 Estrutura de Arquivos

```
pata-nobre-lp/
├── index.html                  # Arquivo principal da Landing Page
├── favicon.ico                 # Ícone da aba do navegador
└── assets/
    ├── styles.css              # Estilos Tailwind CSS compilados
    └── images/                 # Imagens em alta definição
        ├── produto-mao.jpg
        ├── detalhe-microfibra.jpg
        ├── uso-pets.jpg
        ├── detalhe-alca.jpg
        └── og-image.png
```

## 🌐 Como Hospedar na Web

Como se trata de uma estrutura pura (HTML + CSS + Imagens estáticas), você pode hospedar gratuitamente em:
1. **Vercel** (Basta arrastar a pasta `pata-nobre-lp` ou subir via CLI `vercel`)
2. **Netlify** (Arrastar a pasta no Netlify Drop)
3. **Cloudflare Pages** / **GitHub Pages**
4. Qualquer hospedagem cPanel/Apache/Nginx simplesmente enviando os arquivos para `public_html`.
